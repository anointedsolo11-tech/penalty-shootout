# Penalty Shootout ⚽ — Browser Football Game

A fun and fast browser-based penalty shootout game. Choose your direction, beat the keeper and score as many goals as you can in 5 rounds!

## 🔗 Live Demo
👉 [https://rainbow-conkies-36490e.netlify.app](https://rainbow-conkies-36490e.netlify.app)

## ✨ Features
- ⚽ 5 round penalty shootout format
- 🧤 AI goalkeeper with random save logic
- ⬅️ Choose Left, Center or Right shot direction
- 📊 Live score tracking for player vs keeper
- 🔄 Play Again to restart instantly
- 📱 Mobile optimized — tap to play

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/anointedsolo11-tech/penalty-shootout.git

# Open in browser
open index.html
```

## 🎮 How to Play
1. Choose your shot direction — Left, Center or Right
2. The keeper dives randomly
3. Score more goals than the keeper saves in 5 rounds to win!
